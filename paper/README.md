# Signal Tower：BTC 策略帳戶的紙上交易／手動實盤網站

每根 4H K 線收盤後，從 OKX 抓最新資料、重跑策略，產生下一步要做的事，並用網頁呈現：
K 線上的回測與紙上交易進出場、停損線、D 的調倉、資金曲線、回撤、曝險、逐年／每月報酬、逐筆損益、交易紀錄。

- **S1**：4H 通道突破只做多，N20、N30 兩個子帳戶各半；寬度濾網、200 日均線、3×ATR 移動停損、波動目標倉位（上限 1 倍）；OKX BTC-USDT **現貨**，成本 0.12%/邊、無資金費，提示直接寫買賣多少 BTC，停損用現貨止損委託
- **D**：日線趨勢＋動能＋波動目標（現貨、20% 調倉門檻）
- 預設 20,000 USDT，S1 與 D 各 10,000（S1 內 N20、N30 各 5,000），2026-10-20 起算（`config.json`）

## 怎麼開
```bash
cd ~/Documents/btc-backtest && .venv/bin/python paper/server.py
```
然後在瀏覽器開 http://127.0.0.1:8787 。
沒開伺服器時，直接雙擊 `paper/web/index.html` 也能看，但不能記錄成交、改設定或立即更新。

## 公開展示版（GitHub Pages）
公開網站由 `.github/workflows/pages.yml` 在 GitHub Actions 上從 OKX 抓資料、重跑引擎後發布 `paper/web`。觸發方式有兩種：
- **主要**：本機排程每次跑完、發現新 K 線時，用 `gh workflow run` 直接觸發（`config.json` 的 `publish_repo`），GitHub 會立刻執行，收盤後約 5 分鐘更新
- **備援**：GitHub 自己的定時排程（每 15 分鐘嘗試）。實測這個排程常被延遲或丟棄（設每 15 分鐘，曾 7 小時只跑 1 次），只在電腦關機時派上用場
- 沒有本機伺服器時，網頁自動切成唯讀展示版：隱藏立即更新、記錄成交、設定與提示紀錄
- 電腦開著時收盤後約 5 分鐘更新；電腦關機時只靠 GitHub 排程，可能落後數小時。兩根 K 線之間不會重新發布，所以網頁上的「現價」最多落後 4 小時；實盤下單請以本機版為準
- 公開 repo 若 60 天沒有任何提交，GitHub 會自動停用定時排程，需要到 Actions 頁面重新啟用

## 自動更新與通知
```bash
~/Documents/btc-backtest/paper/launchd/install.sh
```
- 台灣時間 00/04/08/12/16/20 點過 2 分自動更新；電腦睡眠時錯過的會在醒來後補跑
- 有「要操作」的指令（進場、上調停損、停損出場、D 調倉）時，跳出 macOS 通知
- 網站伺服器登入後常駐
- 移除：`paper/launchd/uninstall.sh`；紀錄在 `paper/state/engine.log`
- 如果紀錄出現 `Operation not permitted`，到「系統設定 → 隱私權與安全性 → 完全取用磁碟」加入 `.venv/bin/python`（macOS 限制背景程式讀寫「文件」資料夾）

## 轉成正式資金
網站右上「設定」→ 模式改成「正式資金」，起始資金填策略帳戶的實際金額，起算日填開始下單那天。
之後的提示張數照這個資金計算；每次在 OKX 下單後按「記錄成交」輸入實際成交價，網站會對照模型價格算滑價。
模型淨值是照規則算出來的，不會讀你的交易所帳戶；兩者的差距就是執行誤差，要定期對帳。

## 檔案
| 檔案 | 用途 |
|---|---|
| `engine.py` | 抓資料、跑策略（啟動時自檢與 `backtest.donchian` 逐根一致）、產生提示、寫 `web/data.js` |
| `server.py` | 本機網站與 API（只綁 127.0.0.1；拒絕其他網站來源的請求） |
| `config.json` | 模式、資金、起算日、權重、K 線顏色 |
| `web/` | 網頁（預設深色、可切淺色；每張圖右上 ⛶ 放大鋪滿視窗，支援的瀏覽器會同時進入系統全螢幕，Esc 離開；K 線圖用 TradingView lightweight-charts 4.2.0，從 unpkg 載入，需要網路） |
| `data/` | OKX BTC-USDT 現貨 4H K 線（第一次從 `../data/okx_btc_4h.csv` 複製，之後每次補新的） |
| `state/signals_log.csv` | 每次發出的操作指令（事後對照用） |
| `state/fills.csv` | 你輸入的實際成交 |

## 已知限制
- D 的回測在 2021 年和原始 CSV 有差異（20% 門檻有路徑依賴，起算日不同時倉位狀態不同）；2022 年起每年差距在 0.3 個百分點內
- 組合是兩個子帳戶直接相加，不再平衡
- 紙上帳戶開始前（起算日之前）已持有的部位，張數是用回測資金算的，只供參考
